05Решения, которые я принял самКаждое можно отменить отдельно.
  1. Иконки инструментов — временные монограммы CC, Cx, Cu, GP на цветной плашке. Настоящие логотипы подставить после согласования. Имя инструмента дополнительно написано в мета-строке каждой беседы.
  2. Первая строка выдачи выделяется автоматически. Это только обновляет граф — ничего не открывается.
  3. Граф строится после паузы в наборе (~250 мс). Во время набора вместо него — тонкая полоса «построится после паузы».
  4. Счётчики «скрыто политикой» и «нет на диске» и кнопка «Показать ещё» закреплены под списком, а не в конце прокрутки — числа видны всегда.
  5. Файлы missing: первые показаны в выдаче с пометкой, остальные свёрнуты и посчитаны в футере. Во время прохода индекса это число — «уточняется».
  6. Первичное действие для файла — «Открыть» в приложении по умолчанию. Для missing оно недоступно, вторичное ⌘⏎ показывает последнюю версию из индекса.
  7. Клик по узлу в макете выделяет узел, подсвечивает его связи и меняет строку-детали. Перестройка окрестности вокруг нового центра не нарисована.
  8. Режимы графа: «Файлы» — беседа, сообщения со ссылками на файлы, проект и тема как контекст; «Знания» — проекты и темы; «Происхождение» — цепочка сообщение → файл. Нарисован только «Файлы».
  9. «Ничего не найдено» предлагает три шага: снять фильтр, искать любое из слов (⌥⏎ — новая клавиша), повторить в другом контексте — как отдельный поиск, без смешивания выдач.
  10. Подсказки синтаксиса в пустом окне (проект:, тема:, "фраза") — предположение; опираются только на существующие поля.
  11. При свёрнутом графе ⇥ разворачивает его и ставит фокус внутрь. Свёрнутое окно ниже на ~290 pt, список не растягивается.
  12. Первый запуск — одна панель в самом окне, без мастера. ChatGPT без файла экспорта показан как неподключённый источник, а не как ошибка.
  13. Индикатор индекса различается формой: точка — свежий, разомкнутое кольцо — проход, треугольник — отстал.
  14. Ошибка открытия — встроенная плашка под строкой, не модальное окно. ⌘C копирует ID сессии — это чтение, данные не меняются.
  15. Акцент следует системному акценту macOS. В Tweaks — синий, фиолетовый и графит для проверки.
  16. Роли сообщений в графе подписаны как в данных — user / assistant.
