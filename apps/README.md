# apps

Оболочки Crosskit. Ядро лежит в `src/` и собирается двумя целями: библиотекой
(`src/lib.rs`) и CLI (`src/main.rs`). Здесь — приложения поверх него:

- `panel/` — нативная панель macOS на Swift, проект Xcode. Только читает. С этапа UI-3 ищет
  в настоящих контекстах через процесс `crosskit … --json` — мост до демона (ADR 0044), с
  этапа «Чтение через службу» сначала спрашивает её сокет (ADR 0050).
  Что проверено и чем — в [`panel/README.md`](panel/README.md).
- `desktop/` — приложение Crosskit на SwiftUI, macOS 26: задача как карта решений (ADR 0058,
  0059). Только читает, всё берёт у службы. Сборка и запуск — в
  [`desktop/README.md`](desktop/README.md).
- `CrosskitKit/` — общий Swift-пакет приложений: обмен со службой по сокету, её ответы как
  типы, дерево решений и его геометрия. Панель берёт из него обмен по сокету, desktop — всё.

Зависимость идёт только в одну сторону: приложение знает про ядро, ядро про приложения не
знает и ничего из этого каталога не собирает и не вызывает. Говорят они через отдельный
процесс — решение и его причины записаны в
[ADR 0032](../docs/adr/0032-three-applications-and-one-boundary.md).
