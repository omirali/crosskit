# desktop — Crosskit для macOS

Задача как карта решений (`docs/decision-map.md`): слева доска и задачи контекста, в середине
доска или дерево решений выбранной задачи, справа узел с дословной цитатой. Окно читает всё у
службы, решения владельца отдаёт ей же, а карту достраивает командой — модель спрашивает она.
Решения и их причины — ADR 0058, 0059 и 0061, макет —
[`design/CCDesktop.dc.html`](../../design/CCDesktop.dc.html).

## Сборка и запуск

Нужны Xcode 27 и macOS 26 или новее. Из корня репозитория:

```
xcodebuild -project apps/desktop/CrosskitDesktop.xcodeproj -scheme CrosskitDesktop build
APP=$(xcodebuild -project apps/desktop/CrosskitDesktop.xcodeproj -scheme CrosskitDesktop \
      -showBuildSettings | awk -F' = ' '/ BUILT_PRODUCTS_DIR /{print $2}' | head -1)
open "$APP/Crosskit.app"
```

Или откройте `apps/desktop/CrosskitDesktop.xcodeproj` в Xcode и нажмите ⌘R.

Окно читает всё у фоновой службы по её сокету и базу не открывает. Без службы оно скажет,
что она не запущена: `crosskit service install` или `crosskit service restart`. Служба
должна быть сборки, которая знает операцию `task-map`, — иначе окно скажет, что служба
старее его. Каталог данных — `CROSSKIT_DATA_DIR`, если задан, иначе
`~/Library/Application Support/Crosskit`.

## Что на экране

- **Доска** — стартовый экран. Колонки:
  - «Входящие» — кандидаты сшивки;
  - «Не размечены», «В работе»;
  - «Ждут решения» — HEAD основной линии ждёт вас;
  - «Готово».

  На карточке — мини-линия и счётчики рисков, critical красным.
- **Задачи** — подтверждённые владельцем и кандидаты сшивки. Несколько контекстов —
  переключатель внизу списка. В меню строки — переименовать, отметить готовой, вернуть в
  работу; у кандидата — подтвердить с именем или «не задача».
- **Основная линия.** Развилка — точка с вопросом. Ведущая ветка (✓ выбрал владелец,
  ᵃ решил агент) уходит вбок и ведёт линию к следующей развилке. Отклонённые (✗),
  отложенные (○) и брошенные (⊘) — отростки, ждущие решения (?) — синий пунктир. Последняя
  развилка — HEAD. Открытый critical — красная полоса вдоль линии от шага, где он появился,
  до HEAD; high и ниже — метки у своего шага. Переключатель на панели инструментов прячет отклонённые и отложенные
  ветки.
- **Наведение на узел** показывает карточку, откуда он: значок инструмента (Claude Code или
  Codex), беседа, дата, номер реплики, кто её сказал, и цитата. У развилки, сведённой из
  нескольких бесед, и у риска, поднятого в нескольких, — по строке на беседу. Клик по-прежнему
  открывает узел в инспекторе.
- **Беседы** — сколько каждой размечено и что в её карте.
- **Риски** — открытые, принятые и закрытые, находки вне задачи.
- **Узел** (инспектор) — ветки с причинами, цитата, кто её сказал, номер реплики и беседа.
  Кнопка копирует команду, которой беседу продолжают (`claude --resume …`): окно не управляет
  чужим приложением, как и панель.
- **Риск в инспекторе:** «Принять…» или «Закрыть…» с причиной. Принятый риск становится
  серым, перестаёт тянуть полосу и помнит, когда и почему. «Вернуть риск карте» снимает
  решение. Задачу с открытым critical ядро готовой не отметит.
- **Беседы:** что предлагает сшивка — добавить в задачу или «не из этой задачи»; беседу
  задачи можно убрать из её меню.
- **Беседа с агентом** (ADR 0062):
  - «Продолжить задачу» на панели открывает окно беседы с Claude Code в каталоге последней
    беседы задачи;
  - «Продолжить» у беседы во вкладке «Беседы» продолжает её;
  - перед началом видно, какую вводную получит агент — основную линию, отказы, риски, — и
    выбираются разрешения;
  - в ленте текст идёт по мере ответа, вызовы инструментов видны с результатами, а запрос
    разрешения — карточка «Разрешить / Отклонить»;
  - «Стоп» прерывает ход.

  Это настоящая беседа Claude Code с вашими настройками. Её журнал сохраняется, и после хода
  она сама входит в задачу, как только служба её прочитала.
- **Достроить карту** (молоток на панели): окно называет число реплик без карты и оценку цены
  (около 1,1 цента за реплику и 0,43 $ за сводку, ADR 0057), а после согласия запускает
  программу службы `…/Crosskit/bin/crosskit tasks map … --build` через `zsh -l`, чтобы
  нашёлся `claude`. Ход видно строками, «Остановить» прерывает, а размеченное остаётся.

## Код

- `CrosskitDesktop/Model` — состояние окна (`DesktopModel`, `@Observable`), слова и цвета.
- `CrosskitDesktop/Views` — экраны SwiftUI. Дерево рисует `Canvas`, узлы — кнопки поверх.
- Всё, что не про вид, — в пакете [`../CrosskitKit`](../CrosskitKit): `ServiceClient`
  (actor), ответы службы, `DecisionTree` (как ответ ядра становится деревом) и `TreeLayout`
  (где что стоит).

Режим Swift 6 со строгой проверкой конкурентности, изоляция по умолчанию — главный actor.
Проект держит папку `CrosskitDesktop` синхронизированной: новый файл в ней собирается без
правки проекта.

## Проверки

```
cd apps/CrosskitKit && swift test
```

Тесты пакета (Swift Testing) проверяют разбор ответов, дерево, геометрию и клиент на
поддельной службе. На настоящей службе — та же проверка с задачей, которую называет
переменная окружения (имён задач в исходниках нет):

```
CROSSKIT_LIVE_TASK="<задача>" CROSSKIT_LIVE_CONTEXT=work swift test --filter LiveService
```
