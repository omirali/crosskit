# desktop — Crosskit для macOS

Задача как карта решений (`docs/decision-map.md`) и беседа с агентом рядом с ней. Слева
проекты и задачи, в середине карта и расширения вокруг задачи, справа чат. Окно читает всё у
службы, решения владельца отдаёт ей же, карту достраивает командой, а беседы с Claude Code
ведёт само.
- Решения — ADR 0058, 0059, 0061, 0062 и 0063.
- Макет — [`design/UXMain.dc.html`](../../design/UXMain.dc.html), первый запуск —
  [`design/UXEmpty.dc.html`](../../design/UXEmpty.dc.html).

## Сборка и запуск

Нужны Xcode 27 и macOS 26 или новее. Из корня репозитория:

```
xcodebuild -project apps/desktop/CrosskitDesktop.xcodeproj -scheme CrosskitDesktop build
APP=$(xcodebuild -project apps/desktop/CrosskitDesktop.xcodeproj -scheme CrosskitDesktop \
      -showBuildSettings | awk -F' = ' '/ BUILT_PRODUCTS_DIR /{print $2}' | head -1)
open "$APP/Crosskit.app"
```

Или откройте `apps/desktop/CrosskitDesktop.xcodeproj` в Xcode и нажмите ⌘R.

Окно читает всё у фоновой службы по её сокету и базу не открывает. Без службы оно скажет,
что она не запущена: `crosskit service install` или `crosskit service restart`. Служба
должна быть сборки, которая знает операцию `task-map`, — иначе окно скажет, что служба
старее его. Каталог данных — `CROSSKIT_DATA_DIR`, если задан, иначе
`~/Library/Application Support/Crosskit`.

## Что на экране

- **Слева — проекты и их задачи.** Проект — корень git каталога, где шли беседы задачи.
  - Точка у задачи: синяя — ждёт вашего решения, красная — открыт критичный риск, зелёная — в
    работе, серая — карты нет.
  - Поиск находит задачи, чаты и реплики открытых задач.
  - Внизу — контекст (⌘1…⌘9).
- **Карта решений** — главная вкладка.
  - Развилка — точка с номером и вопросом. Ведущая ветка (✓ выбрали вы, А — решил агент)
    ведёт линию дальше. Отклонённые, отложенные и брошенные — отростки, варианты на выбор —
    синий пунктир. Шаг, где задача ждёт вас, помечен «сейчас», к нему ведёт кнопка внизу.
  - Открытый критичный риск — красная полоса до конца линии, остальные — метки у своего шага.
  - Клик по узлу открывает карточку под картой и чат на реплике, которой узел доказан.
  - В карточке: ветки с цитатами, «Выбрать» у варианта (кладёт выбор в строку ввода
    беседы, где задан вопрос), «Принять / Закрыть с причиной» у риска.
  - «Дочитать ≈ N $» достраивает карту после подтверждения цены.
- **Канбан:** предложения Crosskit, «Ждут вашего решения», «В работе», «Карта не построена»,
  «Готово».
- **Изменения** — что git видит в репозитории задачи: ветка против основной вместе с
  незакоммиченным, разница по файлу.
- **Файлы** — папки бесед с метками git и того, что агент в окне читал или правил.
- **Браузер** — страница рядом с беседой. Ошибка консоли, снимок и указанный элемент уходят в
  строку ввода чата.
- **Терминал** (⌃\`) — ваши команды через `zsh -l` в каталоге задачи и команды агента.
- **Чат справа:**
  - реплики выбранной беседы с номерами и «на карте: …» у тех, что доказали узел;
  - «Чаты · N» открывает список бесед задачи с тем, что предлагает сшивка;
  - строка ввода продолжает беседу Claude Code (Codex — новой беседой в той же задаче), и агент
    получает карту как вводную;
  - в живой беседе видно текст по мере ответа, вызовы инструментов с разницей и запросы
    разрешения: «Разрешить», «Разрешать правки в этом чате», «Отклонить»;
  - модель и разрешения выбираются до старта;
  - ⚡ — быстрый вопрос: только чтение, без журнала, ответ исчезает сам.
- **Колокольчик** (⇧⌘U) — центр уведомлений: разрешения, развилки, критичные риски, отстающие
  карты, предложения задач. Решать можно прямо в нём. Системные уведомления — когда окно не в
  фокусе.

## Код

- `CrosskitDesktop/Model`:
  - состояние окна (`DesktopModel`, `@Observable`) и строка ввода (`Composer`);
  - живые беседы (`ChatModel`, `LiveChats`) и уведомления (`Inbox`);
  - терминал и браузер, слова и цвета.
- `CrosskitDesktop/Views` — экраны SwiftUI. Дерево рисует `Canvas`, узлы — кнопки поверх.
- Всё, что не про вид, — в пакете [`../CrosskitKit`](../CrosskitKit):
  - `ServiceClient` (actor) и ответы службы, `TaskSpeech` — реплики задачи;
  - `DecisionTree`, `TreeLayout` и `MapAnchor` — связь реплики и узла;
  - `ProjectGrouping`, `Git` (`WorkingCopy`), `ToolActivity`, `QuickQuestion`, `ShellCommand`.

Режим Swift 6 со строгой проверкой конкурентности, изоляция по умолчанию — главный actor.
Проект держит папку `CrosskitDesktop` синхронизированной: новый файл в ней собирается без
правки проекта.

Отладочная сборка снимает себя без записи экрана:

```
open -n --env CROSSKIT_SNAPSHOT=/tmp/shots --env CROSSKIT_SNAPSHOT_CONTEXT=work "$APP/Crosskit.app"
```

Она проходит по вкладкам, сохраняет PNG и закрывается. Строки сайдбара на снимке не видны —
это ограничение `cacheDisplay`, а не окна.

## Проверки

```
cd apps/CrosskitKit && swift test
```

Тесты пакета (Swift Testing) проверяют разбор ответов, дерево, геометрию и клиент на
поддельной службе. На настоящей службе — та же проверка с задачей, которую называет
переменная окружения (имён задач в исходниках нет):

```
CROSSKIT_LIVE_TASK="<задача>" CROSSKIT_LIVE_CONTEXT=work swift test --filter LiveService
```
