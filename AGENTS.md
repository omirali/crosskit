# Crosskit: инструкции для Codex

Crosskit — локальное Rust-приложение для индексации знаний. Архитектурная цель и
границы системы описаны в [docs/knowledge-graph-architecture.md](docs/knowledge-graph-architecture.md).

Перед изменением кода прочитай применимые правила:

@.claude/rules/00-core.md
@.claude/rules/10-rust-architecture.md
@.claude/rules/20-quality-workflow.md

Если эти правила противоречат явно сформулированной задаче пользователя, приоритет у
задачи пользователя. Не меняй существующий код вне её области только ради косметики.
