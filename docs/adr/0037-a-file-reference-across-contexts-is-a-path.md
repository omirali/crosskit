# ADR 0037: ссылка на файл между контекстами — это путь, а не ребро

Статус: принято 2026-09-25 (Этап 32)

## Контекст

Беседа называет файлы: агент их читает, пишет и правит. Естественное желание — ребро
`Conversation -[:TOUCHED]-> File`, как `Message -[:REFERENCES]-> File` в разделе 4.2
архитектуры.

Этап 32 измерил, куда эти пути ведут. 830 различных путей в 60 беседах контекста `chats`:

| контекст | путей |
| --- | ---: |
| gitlab-two | 256 |
| without-remote | 128 |
| github-com | 62 |
| chats | 51 |
| gitlab-one | 2 |
| **ни в одном контексте** | **331 (40 %)** |

То есть **в своём контексте лежит 51 путь из 830 — шесть процентов.**

## Решение

**`FileTouch.path` — строка. Ребра к `File` нет.**

Контекст — это своя база (ADR 0008), и кросс-запрос между контекстами невозможен физически:
в базе, против которой идёт запрос, чужих файлов просто нет. Это не ограничение, которое
хочется обойти, — это и есть механизм гарантии конфиденциальности.

Отсюда следует, что ребро к `File` можно было бы провести только к тем шести процентам, что
случайно лежат в той же базе. Для остальных 94 % ребра не было бы, и ничто в графе не
отличало бы «файла не касались» от «файл в другом контексте». Ссылка превратилась бы в факт,
верный ровно настолько, насколько совпали границы контекстов, — а совпадать они не обязаны.

Путь — один и тот же факт в любом контексте. Соединить его с файлом — работа читателя, в том
контексте, в котором он стоит. Это ровно то, что раздел 4.4 уже говорит про путь: он не
идентификатор, поэтому хранить его как ссылку честнее, чем изображать идентичность.

**Источник несёт уровень доверия, и перечень закрыт: `tool_input | file_history | command`.**

Раздел 5 архитектуры расставляет их по шкале автопринятия:

```text
путь и hash, прочитанные с диска   auto-accept   ← tool_input, file_history
выполненная команда из лога        observation only ← command
```

Первые два производятся. Третий **объявлен и не производится**, и вот измерение, по которому
так решено: в 10 666 командах Bash нашлось 2 565 различных слов, похожих на путь, из них
существуют 1 012 — **39 %**. Это выше 16 %, которых ждали, но дело не в доле: **глагол
неизвестен в принципе.** `cat` читает, `sed -i` пишет, `rg` не делает ни того ни другого, а
`FileTouch` без глагола — это запись «что-то произошло с файлом», которую нельзя ни проверить,
ни использовать.

Вариант в перечне объявлен, потому что колонка уже хранит закрытое множество: источник,
добавленный позже, должен быть значением, которое у множества было всегда, а не миграцией
всех строк.

## Что это уже даёт

Вопрос «в каком чате трогали этот файл» отвечается точным совпадением пути. На дереве
владельца это, например:

```text
.../alder-core/memory/MEMORY.md                             5 бесед
.../45-разбор_по_контрагентам/ПЕРЕДАЧА_сессия_01.09.md          3 беседы
.../kestrel-bay/app/modules/counterparty/draft_service.py 3 беседы
```

— то есть исходный вопрос владельца, с которого начиналось направление, закрыт данными, а не
ранжированием.

## Чего это не даёт

Команды `crosskit` для такого вопроса пока нет: факт в графе есть, спросить его из терминала
нечем. Это этап 33 — вместе с ранжированием, которое этот этап намеренно не трогал.
