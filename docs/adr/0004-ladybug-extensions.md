# ADR 0004: расширения LadybugDB

Статус: принято 2026-09-18

## Решение

Foundation использует только ядро LadybugDB. `fts`, `vector`, `algo`, `json` и Arrow
не считаются доступными без runtime smoke-test на поддерживаемой ОС. Их добавление
требует отдельной ADR, миграции, проверки fallback-поведения и, для динамических
extensions в Rust-бинарнике, подтверждённой настройки линкера.

## Последствия

`crosskit doctor` на этом этапе проверяет открытие базы и миграции, но не сообщает
частичную готовность поиска как успех. Поиск и аналитика появятся только после
совместимого extension-slice.

## Развитие

Отдельная ADR для `fts` написана на этапе 7 — **ADR 0011**, и решение по ней
отрицательное. Smoke-test пройден: расширение грузится из локального файла и работает без
сети. Отклонено не по работоспособности, а по цене фиксации в сборке и потому, что один
индекс несёт один стеммер, а корпус двуязычный. `vector`, `algo`, `json` и Arrow
по-прежнему не рассматривались.
