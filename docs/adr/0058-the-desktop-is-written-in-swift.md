# ADR 0058: desktop пишется на Swift

Статус: принято 2026-10-30 решением владельца. Меняет решение 1 ADR 0032 в части desktop:
вместо Tauri — нативное приложение на Swift. Остальное в ADR 0032 остаётся в силе: приложений
три, граница между приложениями и ядром — процесс.

## Контекст

ADR 0032 (25 сентября) назначил desktop на Tauri и отложил его на конец. С тех пор изменилось
три вещи.

- **Граница, которой ждал ADR 0032, построена.** Фоновая служба владеет базами и отвечает по
  сокету (ADR 0049, 0050). Приложению больше не нужно ни линковать ядро, ни открывать базу.
- **Нативный код уже есть.** Панель (`apps/panel`) — около 6 900 строк Swift: клиент сокета
  службы, источники выдачи, цвета и шрифты, граф Cytoscape в запечатанном `WKWebView`
  (ADR 0046).
- **Desktop стал главным лицом продукта, а не последним этапом.** Задача показывается картой
  решений, сшитой из бесед Claude Code и Codex (`docs/decision-map.md`, ADR 0051–0057), а
  дальше Crosskit сам ведёт беседы с агентами поверх их собственных клиентов.

Владелец работает на macOS, а Windows и Linux — единственное, что Tauri давал сверх Swift.

## Решение

1. **Desktop — нативное macOS-приложение на Swift, в `apps/desktop/`.** По умолчанию SwiftUI;
   AppKit — там, где SwiftUI не хватает.
2. **Современный Swift, а не Swift 5 панели:**
   - режим языка Swift 6 со строгой проверкой конкурентности;
   - Observation (`@Observable`) для состояния экранов;
   - `async`/`await` и actor для клиента службы;
   - Swift Testing для тестов.
3. **Общее у панели и desktop — один Swift-пакет:** протокол службы, модели ответов, цвета и
   шрифты. Код панели переходит в пакет тогда, когда он нужен desktop, а не заранее.
4. **Граница не меняется.** Desktop говорит со службой по сокету тем же протоколом, что панель
   и CLI. Базу он не открывает, ядро не линкует. Чего служба ещё не отдаёт, то добавляется в
   службу, а не в приложение.
5. **Минимальная версия — macOS 26.** С неё начинается нынешний внешний вид системы и почти всё
   современное в SwiftUI, а охват при этом широкий: по телеметрии 2026 года macOS 26 стоит на
   большинстве Mac (около 61 % у пользователей Homebrew в сентябре, 64–86 % по другим
   счётчикам), а macOS 15 — около 12 %. Возможности новее macOS 26 используются только с
   проверкой `#available`. Если перед публикацией понадобится macOS 15, минимум понижается
   отдельным решением, и для новых возможностей дописываются запасные варианты.
6. **Граф остаётся в Cytoscape** (ADR 0046). Как рисовать карту решений — нативно в SwiftUI
   или в веб-виде, — решает этап, который её рисует.

## Что это стоит

- Desktop работает только на macOS. Если понадобится другая платформа, это будет отдельное
  решение.
- Сборка требует Xcode 27 (Xcode 16.4 с SDK macOS 15.5 не знал API macOS 26). На машине
  разработки Xcode обновлён до 27.2 30 октября.
- На macOS 15 и более ранних desktop не запустится. Панель и CLI это не затрагивает: у
  панели минимум прежний, macOS 15.
