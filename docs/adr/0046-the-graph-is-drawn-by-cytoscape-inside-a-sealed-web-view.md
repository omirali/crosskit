# ADR 0046: граф рисует Cytoscape.js в запечатанном веб-виде

Статус: принято 2026-10-02 (Этап UI-4b). Меняет решение 8 ADR 0045 (своё рисование). Схему
графа не меняет; машинный ответ поднимает номер до 2.

## Контекст

UI-4 рисовал граф своим кодом и вслепую: у оболочки не было разрешения «Запись экрана». Первый
же снимок владельца (беседа о ревью проекта, ⇥) показал, что граф не читается:

- холст — белый прямоугольник на тёмной панели, не в теме окна;
- легенда налезает на карточку узла;
- два узла проекта, один подписан закодированным именем папки бесед;
- узлы-реплики `#83 · вы` без текста ничего не говорят, а их связь с файлом выведена по времени
  и подана как факт;
- линии без подписей: не видно, правила беседа файл, читала или владелец его назвал;
- один файл двумя узлами — в контексте и «вне контекста»;
- «глубина 2», а второго шага нет, и не сказано, что он пуст.

Владелец просит зрелую, оттестированную библиотеку вместо своего рисования.

## Решение 1: Cytoscape.js с dagre, в `WKWebView`

**Cytoscape.js 3.34.3** рисует, **cytoscape-dagre 4.0.1** раскладывает (dagre v3 и graphlib
встроены в его сборку). Всё MIT. Веб-вид — системный WebKit, не зависимость приложения.
Рассмотрены:

| кандидат | решение | почему |
| --- | --- | --- |
| **Cytoscape.js + dagre** | **выбран** | зрелый (с 2012), раскладка по уровням слева направо — ровно «проект → беседа → файлы → соседние беседы»; стиль данными, а не кодом; MIT; два файла |
| Graphviz (`dot`) | отказ | C-библиотека в сборке Xcode с её зависимостями (expat, cairo для картинки); рисует картинку, а не интерактивный граф — клик, выбор, тему пришлось бы делать поверх |
| Grape (Swift/SwiftUI) | отказ | молодая (силовая раскладка, без уровневой), API ещё меняется; силовая раскладка — ровно то, от чего отказался раздел 15 архитектуры |
| vis-network | отказ | уровневая раскладка есть, но слабее dagre на широких уровнях; тяжелее (≈ 0.7 МБ) и с собственным DOM поверх canvas |
| ELK.js | отказ | лицензия EPL-2.0 — слабый копилефт, отдельное решение о публикации; ≈ 1.5 МБ ради раскладки, которую dagre уже даёт |

Файлы **вендорены** (`apps/panel/CrosskitPanel/GraphPage/vendor/`): минифицированные, версии
закреплены, рядом `LICENSE-*` каждой из четырёх библиотек, запись с SHA-256 — в `NOTICE`.

Своё рисование UI-4 (`GraphCanvas`, `GraphLayout`) удалено, а не оставлено вторым путём.

## Решение 2: веб-вид запечатан

- Страница и скрипты — только из каталога `GraphPage` в бандле (`loadFileURL` с доступом на
  чтение к нему одному). Делегат навигации отменяет любой переход за пределы этого каталога.
- Content-Security-Policy страницы: `default-src 'none'; script-src 'self'; style-src 'self'
  'unsafe-inline'`. Сети нет: ни CDN, ни `fetch`, ни картинок. `'unsafe-inline'` — для стилей,
  которые Cytoscape ставит своим элементам; скрипты по-прежнему только из файлов.
- Хранилище — `nonPersistent`: ни cookies, ни localStorage на диске.
- Swift → страница: постоянное тело `window.crosskitGraph.render(payload)` или
  `.select(payload)` и данные **значением аргумента** `callAsyncJavaScript`, разбираемые
  `JSON.parse`. Строка из чужого транскрипта не может стать кодом — это проверяет тест с
  враждебным идентификатором.
- Страница → Swift: сообщения `tap` (идентификатор узла), `rendered` (номер вида) и `ready`.
  Прочее отбрасывается.
- Клавиатура: веб-вид не берёт первого ответчика (`acceptsFirstResponder = false`). Строка запроса
  остаётся им, ⇥ ↑↓ ⏎ esc разбирает панель и передаёт графу вызовом (`select`).

## Решение 3: ядро говорит то, что знает, и не больше

Схема машинного ответа — **2** (общая для `search`, `contexts`, `graph`; поля выдачи не менялись).

- **Файл — один узел.** «Вне контекста» — его состояние (`file.state = "outside"`), а не вид узла.
  Путь касания, записанный относительно (`docs/…`), читается от корня проекта беседы: на дереве
  владельца он и был вторым узлом того же файла. Две записи одного файла одной беседой
  складываются: глаголы объединяются, счёт суммируется — иначе вторая теряла бы свою метку
  («правила ×12» пропадало за «создала ×2»).
- **Проект — один узел** с именем по последнему сегменту корня. Папка бесед
  (`~/.claude/projects/<код>`) — часть проекта, чей код совпадает с её именем (или с началом
  имени — сессия, начатая в подкаталоге). Сравнивается в направлении кодирования, ничего не
  раскодируется (`transcript_folder::project_of_folder`).
- **Выведенное помечено.** Ребро касания от реплики несёт `by_time: true`: реплика найдена как
  последняя, сказанная не позже касания, а не прочитана из записи.

## Решение 4: что рисует панель

Перевод вида в элементы — `GraphPicture.swift`, без WebKit, под тестами:

- **реплик на холсте нет.** Касание — линия «беседа → файл» с подписью: «правила ×12 · вы
  назвали», «создала», «читала». Номер реплики и момент — в карточке файла, с пометкой
  «определена по времени»;
- «только читала» — точки, «вы назвали» — линия акцентом;
- больше 12 линий касания — подписи только у выбранного узла (сорок пять подписей подряд были
  стеной текста); полная подпись всегда в карточке;
- у файла того же проекта, что его беседа, своей линии проекта нет — она перечёркивала граф;
- подписи узлов до 28 знаков, целиком — в карточке.

Вокруг страницы — нативное, стопкой, ничего не перекрывает: строка-объяснение сверху («Беседа и
файлы, которые она меняла или вы называли. Правее — другие беседы тех же файлов»; для файла —
своя), строка о пустоте («У этих файлов других бесед нет», «Эта беседа не правила файлов и не
называла их»), под холстом легенда и карточка. Цвета — токены `Tokens.swift` в текущем
оформлении, переданные странице с каждым видом; фон холста прозрачный, под материал окна.

`WKWebView` и страница создаются при запуске панели вместе с окном; ⇥ только передаёт данные.

## Измерено

Дерево владельца, контекст `work`, 2 октября 2026. Панель — Debug, ядро — `cargo build
--release`. `--graph-replay`, по 20 видов на случай, по кругу; первый ⇥ — отдельно, через секунду
после того, как страница сообщила о готовности. Состояние машины: `vm.loadavg` 2.36 перед
прогоном, 2.00 после; сверху `ps` — процессы по 3–4 % (браузер, расширение редактора). Перед
этим прогон ждал, пока нагрузка от сборок и съёмки (7.9) не спадёт ниже 3.

**От ⇥ до кадра с графом:**

| фокус | глубина | узлов | p50 | p95 | процесс ядра, p50 | страница, p50 |
| --- | --- | --- | --- | --- | --- | --- |
| беседа на 2 016 реплик | 2 | 100 | 349.9 мс | 383.3 мс | 300.1 мс | 43.6 мс |
| файл, который трогали 5 бесед | 2 | 100 | 357.4 мс | 366.6 мс | 307.3 мс | 41.4 мс |
| первый ⇥ после запуска (n = 1) | 2 | 100 | 687.3 мс | — | 543.3 мс | 128.8 мс |

«Страница» — от разобранного ответа до сообщения `rendered`: передача JSON, раскладка dagre,
отрисовка Cytoscape и два кадра анимации. У собственного рисования UI-4 то же место стоило 8 мс:
библиотека добавила ≈ 35 мс к виду из ста узлов, p95 вырос с 342–349 до 367–383 мс. Процесс ядра
не изменился (≈ 300 мс, ADR 0045). Первый ⇥ после запуска дороже вдвое: первая раскладка
страницы (129 мс, JIT ещё холодный) и холодный кэш ядра. Он измерен один раз — это первый вид
одного запуска.

**Память.** Процесс панели: 19.0 МБ до окна и веб-вида, 83.8 МБ со страницей графа (`task_info`,
печатается при запуске; `ps` через 6 с — 93 МБ). Страница живёт в процессах WebKit, которых
процесс панели не видит: `WebContent` — 115 МБ, `GPU` — 38 МБ, `Networking` — 17 МБ (`ps`, новые
процессы после запуска панели). Итого граф стоит около 235 МБ резидентной памяти на машине,
постоянно, пока панель запущена.

**Поведение окна.** Протокол показа печатает фронт до и после: «фронт до «Telegram» → после
«Telegram»», `key=true`, строка запроса — первый ответчик. Клавиатуру и клик по узлу живой рукой
этот этап не проверял: у оболочки нет «Универсального доступа», подделать событие нечем.
`acceptsFirstResponder = false` держит клавиатуру у панели по построению.

**Снимки.** «Запись экрана» у процесса, из которого шла работа, не действовала: `screencapture
-l` отказывал, весь экран снимался без чужих окон. Снимки сделаны средствами самой панели
(`--snapshot`): AppKit рисует окно (`cacheDisplay`), WebKit — страницу (`takeSnapshot`). Отличие от
экрана одно — нет размытия материала: его делает оконный сервер, и в снимке вместо него сплошной
фон окна этой темы.

## Вердикт

Библиотека не ломает поведение панели: окно не забирает фокус, клавиатура остаётся у строки
запроса, ⇥ стоит на 35 мс больше. Цена названа числами: ≈ 235 МБ памяти и 35 мс на вид. Если
память станет доводом, следующий шаг — создавать веб-вид по первому ⇥ и отпускать его через
минуту простоя, а не своё рисование: первый ⇥ тогда стоил бы ещё загрузку страницы.

## Чего этот этап не делает

- Режимов «Файлы / Знания / Происхождение» нет — вид один.
- Текста реплики нет: `Message` хранит роль и момент.
- Касание, записанное относительным путём, из другой беседы на втором шаге не находится: шаг от
  файла ищет касания по его настоящим путям.
- Вид из сотни узлов выше холста и листается колесом; при этом его нельзя увидеть целиком.

## Поправка 2026-10-13: граф двигается так же, как карта знаний

Владелец попросил на ⇥ ту же навигацию, что на ⌘M (ADR 0048, поправки 3 и 4). Пункт «вид из сотни
узлов листается колесом, и его нельзя увидеть целиком» снят: щипок и колесо с ⌘/⌃ приближают к
курсору, два пальца и перетаскивание фона сдвигают, ← → ↑ ↓ — сдвиг на 15 % (⇧ — 50 %), + = − —
масштаб к середине, 0 и кнопка ⤢ — весь граф. **Механизм — общий с картой, не копия:** окно
(`PanelWindow.sendEvent`) ловит клавиши и жесты, пока на экране холст; клавишу разбирает
`CanvasKey`, жест — `GraphPage.gesture`, двигает камера `camera.js`, которую подключают обе
страницы. Прежний обработчик колеса в `graph.js` снят: до страницы колесо больше не доходит.

**Конфликт клавиш.** ↑ ↓ выбирали узел; теперь они двигают холст, а узел выбирают **⌥↑ / ⌥↓**.
⇥ / ⇧⇥ по узлам отвергнуты: ⇥ на графе — «к выдаче», и его пришлось бы отнять. ⏎ на выбранном —
как раньше. Выбранный узел подводится в видимую часть и по горизонтали: холст теперь сдвигают.

**Проверено пробой** (`--graph-focus=… --probe-gestures`, синтетическая песочница
`graph_sandbox.py`, большая беседа, холст 760 × 320 pt): два пальца — сдвиг на 80 и 60 pt; ⌃-колесо —
зум 0,948 → 0,636; → / ← — ±114 pt; удержание → — 228 pt; ↓ — 48 pt, ⇧↑ — 160 pt; + и = — ×1,3,
− — ÷1,3; 0 — весь граф (зум 0,240); ⏎ на фокусе — «скопировал бы claude --resume …»; ⌥↓ ⌥↓ — выбор
сдвинулся на второй узел, холст подвёл его в видимую часть; ⏎ — «открыл бы файл …». ⏎ в пробе
ничего не открывает и буфер обмена не трогает. **Не проверено:** щипок — его не синтезировать.
